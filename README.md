# 공천만 주십시오

“그때는 맞고, 지금은 다릅니다.”

가상 정당과 인물로 만드는 한국어 정치 풍자 카드게임. **개발 중인 압축 플레이판**이며 전체 기획의 완성판이 아닙니다.

## 실행

Node.js 24 이상. 외부 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 http://localhost:4173 접속. 방향키, 좌우 드래그, 선택 버튼을 지원합니다.

```sh
npm run build
npm test
npm run simulate
```

`dist/`를 정적 호스팅에 올리면 배포됩니다. 현재 빌드는 Node의 TypeScript 문법 제거 기능을 사용하며 정적 타입 검사는 수행하지 않습니다. 개발 서버를 바꾼 뒤에는 빌드를 다시 실행합니다. 폰트만 Google Fonts에서 불러오며 오프라인에는 시스템 글꼴로 대체됩니다.

## 현재 플레이

프롤로그 → 직업 선택 → 20개 사건의 첫 공천과 지방선거 → 재기·정당 이동·법적 분쟁 → 국회의원 선거 → 대선 → 결산. 36번의 주요 선택과 세 번의 선거로 구성한 압축 경로입니다. 본편 발언 4개를 기록하고 특검·부동산·청년 정치의 3개 연쇄에서 실제 발언을 다시 참조합니다. 가족은 누나로 설정하여 배우자·자녀를 전제하지 않습니다.

8종 SVG 직업 캐릭터, 초기 4개 직업과 완주로 해금하는 4개 직업, 8명 NPC, 5개 정당명, 지역 조직·신뢰·공개 능력치, 시드 기반 선거, 낙선 후 진행, 대통령 당선·기타 엔딩, 관계와 이력 화면을 제공합니다.

저장 위치는 브라우저 localStorage입니다. 메뉴 → 설정에서 JSON 내보내기·가져오기가 가능합니다. 저장 버전 및 구조를 검증하고, 유효하지 않으면 기존 진행을 유지합니다. 본편 저장과 프롤로그 기록은 분리합니다. 장치 간 동기화는 없습니다.

## 검증과 한계

`DEVELOPMENT_STATUS.md`에 실제 실행 결과와 미구현 범위를 기록했습니다. 브라우저 제어 도구 부재로 실제 모바일·PC 플레이 검증은 수행하지 못했습니다. 자동 시뮬레이션은 재미나 사람의 당선율을 증명하지 않습니다.

## GitHub·Cloudflare Pages 게시

[배포 안내](DEPLOYMENT.md)의 Git 연동 방식으로 게시합니다. Node.js 24.19.0, 빌드 `npm ci && npm run build`, 출력 `dist`, Production branch `main`을 사용합니다. 비밀 키와 서버 기능은 필요 없습니다. 소스 다운로드는 게시 후 GitHub 저장소의 초록색 **Code → Download ZIP**에서 할 수 있습니다.
