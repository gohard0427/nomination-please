# 국민의 뜻에 따르겠습니다

“그때는 맞고, 지금은 다릅니다.”

**게임 접속: https://nomination-please.pages.dev**

가상의 인물·정당으로 만드는 한국어 정치 풍자 카드게임입니다. 이전 이름은 〈공천만 주십시오〉이며 저장 호환성과 기존 공개 주소는 유지합니다.

## 이번 수정판

- 승인받은 캐릭터 시안의 직업 8종과 주요 NPC·정당 대표·대통령 삽화
- 어두운 화면, 작은 NPC 초상, 큰 질문, 두 개의 선택 버튼. 드래그 선택 제거
- 공개 능력치 4개: 지지율·정치자금·인지도·당내 입지(무소속은 독자 기반)
- 12개 사회집단의 반응, 중복 없는 48개 공동 특성 프로필 × 3개 가상 권역
- 인지도와 호감 분리, 지역/전국 평가 범위 안내
- 12정책 분야, 실제 활동에 근거한 입당 제의, 정당 5개, 공천·선거·후속 협력
- 총 60번의 주요 선택, 지방·국회·대선 3회, 낙선과 무소속의 재기, 대선 승리 엔딩
- 과거 발언 부메랑, 가족 의혹, 법적 절차, NPC 기억과 관계 유지
- v1 저장 원본 보관과 v2 변환, 결과 화면까지 자동 저장, JSON 내보내기·가져오기

지지율은 **현재 범위에서 나를 알고 평가하는 사람들의 긍정 평가 비율**입니다. 예상 득표율과 다릅니다. 선거는 비인지자·경쟁 후보·정당 선호·현장 참여까지 따로 반영합니다. 내부 집단 지지·신뢰·관계 수치는 일반 화면에 표시하지 않습니다. 집단은 실제 사람에 대한 고정된 정치 성향이 아닌 게임용 합성 모델입니다.

## 설치·실행

Node.js 24.19.0 권장. 환경 변수·API 키·백엔드·데이터베이스는 필요 없습니다.

```sh
npm ci
npm run dev
```

개발 서버는 4173번 포트를 사용합니다. 소스를 바꾼 뒤 개발 서버를 다시 실행하면 빌드를 갱신합니다.

```sh
npm run build       # TypeScript 정적 검사 + dist 생성
npm test            # 엔진·데이터·복구 테스트
npm run simulate    # 4,000회 자동 선택 시뮬레이션
npm run test:browser # Chromium 브라우저 실제 UI 시나리오
```

브라우저 테스트는 시스템 Chromium을 사용합니다. `CHROMIUM_PATH`로 실행 파일을 지정할 수 있습니다. 이미 실행 중인 개발 서버를 대상으로 하며, `TEST_BASE_URL`로 배포 URL도 검사할 수 있습니다. 스크린샷은 기본적으로 /tmp/nomination-qa에 저장합니다. 이 경로는 개발자 QA용이며 사용자의 접속 주소가 아닙니다.

## 저장과 복구

저장은 해당 브라우저·도메인에 보관됩니다. 브라우저 데이터를 삭제하면 사라질 수 있으니 설정 → 진행 파일 내보내기로 보관하세요. 장치 간 자동 동기화는 없습니다.

v1 진행을 처음 읽으면 원본을 `nomination-please-v1-backup`에 보관하고 v2 상태를 생성합니다. 원래 v1 항목도 삭제하지 않습니다. 과거 선거·발언·진행 순서를 유지하며, 과거에 없었던 집단 반응을 새로 만들어 넣지 않습니다. v1 회차는 기존 36선택 경로를 이어갑니다. 새 회차부터 60선택 경로를 사용합니다. 가져오기 전 상태와 새 회차 시작 전 상태도 별도 백업합니다. 손상된 파일은 진행을 바꾸지 않고 거부합니다.

## 개발자용 분석

```sh
npm run debug:save -- 진행파일.json
```

내부 유권자·집단 투영·영입 근거를 CLI에서 확인합니다. 로컬 개발 서버에만 `window.__politicsDebug()`를 제공하며 선택 시간과 첫 부메랑·선거 턴을 검사할 수 있습니다. 공개 호스트에는 이 진입점을 제공하지 않습니다. 히든 수치는 UX상 비공개이며, 클라이언트 저장 파일 자체를 암호화한 서버 비밀이라는 뜻은 아닙니다. 외부 분석 서비스로 전송하지 않습니다.

## 범위와 남은 과제

현재 60개의 고유 주요 사건과 고정된 기본 진행 경로에 조건별 제의·본문·관계·선거 결과를 연결했습니다. 무작위 대규모 사건 추첨, 희귀 보좌관 다중 진실, 다양한 가족 진실, 대통령 취임 후 운영은 구현하지 않았습니다. 캐릭터는 승인 이미지의 삽화 영역을 보여주는 WebP 스프라이트이며 고령화·직책별 새 의상·전 인물 표정 애니메이션은 추후 과제입니다. 실제 사람의 재미와 목표 당선율을 자동 테스트로 검증했다고 주장하지 않습니다.

구현 상태와 실제 검증 결과는 [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md)에 기록합니다.
